	modelling technique inspired by Object Role Modelling. Now archived; for
	fact-based modelling, use LinkML instead.
- [Apache Avalon](https://github.com/lsimons/avalon) / [Apache Excalibur](https://github.com/lsimons/excalibur) - Java software for component and container programming that pioneered design patterns such as Inversion of Control (IoC) and Separation of Concerns (SoC). I worked on them for many years and made a GitHub archive of their Subversion code.
